## Context

Phase 0 (capture) and Phase 1 (route-change watchdog) are done, review-hardened, and pushed (`master` @ `4cdde89`). The capture layer produces aligned, channel-separated **16 kHz mono f32 WAVs** and Phases 2–3 were de-risked end-to-end via an external `openai-whisper` CLI on a real 5-min Spanish Google Meet. **Phase 1.5 provisions the on-device ASR model** so Phase 2 (VAD + whisper-rs per channel) can wire it in without any surprise blockers.

**Why now / what it de-risks:** the master plan sequences provisioning + RTF validation *before* the Phase-2 pipeline so that "a broken CoreML conversion can't block Phase 2." Two things must be true before Phase 2 is safe to build: (1) the model + a working CoreML encoder exist on disk at a recorded location, obtained by a **deliberate, logged** step (zero-telemetry design goal → **no silent runtime download**); (2) the **real engine (whisper-rs) actually builds with metal, then coreml, on this exact toolchain** (Rust 1.95 / macOS 26.5 / arm64 / Xcode) and loads the encoder — this build, not just the model artifact, is the true Phase-2 blocker.

**Model decision (user):** the **biggest/best** multilingual model = full **`large-v3`** (32 decoder layers, ~1.5 B params). Meetings are Spanish → multilingual is mandatory (RESUME frozen invariant; supersedes the stale "English-first" line in master-plan §2.3). Tradeoff accepted: slower than `large-v3-turbo`, but v1 is **batch-at-finalize** so faster-than-realtime is all that's needed; turbo remains a drop-in swap later.

## Design

### Model artifacts + provisioning (deliberate, logged — the "no silent download" requirement)
- New `models/` dir. Committed: `models/provision.sh` (the explicit, reproducible provisioning step) + `models/PROVISIONING.md` (the log: model choice + rationale, exact source URLs, sha256, sizes, on-disk paths, date, final RTF numbers). **Binaries gitignored.**
- `models/provision.sh` (pinned URLs, integrity-checked, idempotent):
  1. Download `ggml-large-v3.bin` from `https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3.bin` → `models/ggml-large-v3.bin`.
  2. **Verify integrity:** fetch the expected sha256 from the HF LFS pointer (`curl -sL .../raw/main/ggml-large-v3.bin` returns `oid sha256:<hash>`), compare against `shasum -a 256` of the download; abort on mismatch.
  3. Download `ggml-large-v3-encoder.mlmodelc.zip`, `unzip` → `models/ggml-large-v3-encoder.mlmodelc/` (a compiled CoreML dir; sanity-check it contains `coremldata.bin`/`model.mil`), remove the zip.
  4. Print final paths + sizes; the script is re-run-safe (skip if present + sha ok).
- **whisper-rs CoreML naming contract:** with the `coreml` feature, whisper.cpp derives the encoder path from the ggml path — `models/ggml-large-v3.bin` → `models/ggml-large-v3-encoder.mlmodelc`. The two files **must sit side-by-side with exactly these names** (the HF zip already unpacks to that name).

### `Cargo.toml` — introduce whisper-rs (metal baseline + optional coreml feature)
Mirror the verified `docs/meetily-ref/Cargo.toml` recipe, into the existing `cfg(target_os="macos")` block:
```toml
[target.'cfg(target_os = "macos")'.dependencies]
cidre = { git = "https://github.com/yury/cidre", rev = "a9587fa", features = ["av"] }
ringbuf = "0.4.8"
whisper-rs = { version = "0.13.2", default-features = false, features = ["raw-api", "metal"] }

[features]
default = []
coreml = ["whisper-rs/coreml"]
```
→ `cargo build` = **metal-only** baseline; `cargo build --features coreml` = **metal + CoreML**. This *is* the plan's "metal-only first, then enable coreml" toggle, expressed as a Cargo feature so CoreML is cleanly separable and can't block the metal path.

### `src/bin/rtf_probe.rs` — throwaway RTF + accuracy probe (~70 lines)
A minimal, capture-free binary (no mic/system-audio → **no TCC, no re-sign needed** — the frozen signing ritual is a *capture-binary* concern and does not apply here):
- Args: `--model <path>` (default `models/ggml-large-v3.bin`), `--wav <path>` (default `capture/system.wav`), `--lang <code>` (default `es`).
- Read WAV via `hound`; **assert 16 kHz mono f32** (clear error otherwise — 48 kHz→16 kHz rubato resample is a Phase-2 job, and the on-disk test files are already 16 kHz).
- `WhisperContext::new_with_params(model, default)` → `state.full(FullParams{ language=Some("es"), … })`.
- Print: audio seconds, wall-clock seconds, **RTF = wall/audio**, and the first N decoded segments (for eyeball Spanish-quality check vs the `small` reference).
- Log whether CoreML engaged (whisper.cpp prints "loading Core ML model …" vs a CPU/GPU fallback warning) so Batch 2 can confirm the encoder actually loaded.

### `.gitignore` — add model-artifact ignores
Append `/models/*.bin`, `/models/*.mlmodelc/`, `/models/*.zip` (keep `provision.sh` + `PROVISIONING.md` tracked).

## Implementation batches (each: run → observe real output, not just a green build)

**Batch 0 — Provision the model + CoreML encoder.** Write `models/provision.sh` + `.gitignore` ignores; run it. **Verify:** `ggml-large-v3.bin` (~2.9 GB) present + sha256 matches the HF LFS pointer; `ggml-large-v3-encoder.mlmodelc/` unpacked and contains `coremldata.bin`/`model.mil`; both named per the side-by-side contract.

**Batch 1 — whisper-rs metal-only + `rtf_probe`; measure RTF + Spanish accuracy.** Add whisper-rs (`raw-api,metal`) + the `coreml` feature stanza; write `src/bin/rtf_probe.rs`; `cargo build --bin rtf_probe` (**de-risks the whisper-rs metal C++ build on this toolchain**). Run on `capture/system.wav`. **Verify:** builds; RTF printed and **< 1.0× (faster than realtime — informational bar, not a gate)**; Spanish transcript coherent and **visibly better than the `small` reference** (`capture/transcript_5min.txt` — fewer jargon/proper-noun errors).

**Batch 2 — Enable CoreML; re-measure warm; confirm the encoder loads.** `cargo build --bin rtf_probe --features coreml` (**de-risks the coreml build + CoreML.framework link**). Run **twice** (first run ANE-compiles/​warms the `.mlmodelc` — measure the *warm* run, not cold). **Verify:** coreml build succeeds; logs confirm the Core ML encoder **loaded** (not a CPU/GPU fallback warning); warm RTF recorded vs metal-only; transcript still coherent. **Fallback (explicit):** if the coreml build/load fails, Batch 1's metal-only path already unblocks Phase 2 — record the failure in `PROVISIONING.md`, mark CoreML deferred, and continue (this is exactly the outcome the metal-first sequencing protects against).

**Batch 3 — Record + persist + review + push.** Fill `PROVISIONING.md` with final metal-vs-coreml RTF, paths, sha, date. Update `RESUME.md` + brain memory (Phase 1.5 done, model = large-v3, paths, RTF). ## Assumptions & risks (stated, non-blocking)
- **whisper-rs 0.13.2 metal/coreml C++ build** on Rust 1.95 / macOS 26.5 / Xcode could churn (pre-1.0-adjacent FFI). *Mitigation:* metal-first isolates coreml; if 0.13.2 fails to build, bump whisper-rs to latest (independent of the cidre pin) and re-try — the RTF probe is throwaway, so a version bump is cheap.
- **CoreML first-run ANE-compile latency** (tens of seconds) inflates a cold RTF. *Mitigation:* measure the warm run.
- **large-v3 is slower than turbo.** *Mitigation:* v1 is batch-at-finalize; RTF is measured not gated; turbo is a drop-in swap via the same `provision.sh` if ever needed.
- **Pre-converted `.mlmodelc` vs whisper.cpp CoreML-runtime version.** *Mitigation:* it's the official artifact; metal fallback covers any mismatch.
- **First dep change since Phase 0** lengthens every subsequent `cargo build` (whisper.cpp compiles once, then caches). Acceptable — pulls the Phase-2 build cost forward by one phase, which is the point (de-risk early).
